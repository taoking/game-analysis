# 末日 × 陪伴 × 生存｜游戏设计与竞品研究

**Post-apocalypse · Companionship · Survival · Ambient Games**

基于 **32 款作品 / 7 类机制** 的案例库（2026-11-13）。目的不是罗列末日排行榜，而是寻找一个有趣的设计交集：**残酷世界里的安全感，和现实生活中的温和、长期陪伴**。

## 当前样本一览

| 指标 | 数量 |
| --- | ---: |
| 游戏总数 | **32** |
| 末日/灾变核心样本 | **17** |
| 现实危机生存样本 | **1** |
| 跨题材机制参照 | **14** |
| 情感关系维度 ≥ 4 | **14** |
| 低打扰维度 ≥ 4 | **13** |

**统计限制**：这是人工挑选的 **32 款游戏样本**，不是全市场统计、销量份额或玩家调研；三个 0–5 分数是编辑主观评估，不是官方评分。
