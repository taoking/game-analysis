# 《风雪之外》：从研究得到的 Web Demo 方案

> 本文是**可验证的设计假设**，不是最终锁定的 PRD。研究目标是验证“现实专注—自主生活—回访成长—短途探索—回家”的闭环是否有趣。

## 愿景

一间偏远气象站木屋，外面风雪危险，里面有炉火、茶、无线电与生活着的角色。用户现实里学习或工作时，角色在木屋内独立生活，偶尔偏向读书、整理等安静活动。玩家回来能看到经历、环境和“时光手记”的积累。

## 三个不可牺牲的原则

1. **生存有张力但没有打卡式惩罚**：气象、燃料和储备支持“风雪之外”的真实感；离线不因用户缺席而死亡。
2. **角色不是按钮的附属品**：安全与生存优先，自主日常次之，现实专注引起轻微行为倾向，不要求角色严格同步。
3. **成长是痕迹不是 KPI**：真实专注和探索可带来少量收藏、空间变化、里程碑与时光手记，而非迫使刷经验。

## 产品核心循环

```text
现实开始工作 / 学习
     ↓
角色自主生活（添柴、读书、整理、休息）
     ↓
玩家偶尔看一眼窗外风雪和室内火光
     ↓
结束现实专注并回访（发生过什么？）
     ↓
短途探索（采柴、寻旧物、观察天气）
     ↓
带回收获 / 留下痕迹 / 记录时光手记
     └──────────────────→ 继续共同生活
```

## MVP 功能拆分

| 维度 | 首版必须验证 | 后续再考虑 |
| --- | --- | --- |
| 场景 | 1 间木屋、炉火、风雪窗、桌椅、收音机 | 多建筑与完整地图 |
| 自主角色 | 6–8 个自然状态：休息、添柴、看雪、读书、整理、喝茶、短暂闲坐 | 大模型驱动开放日程 |
| 环境 | 日夜变化、暴风雪强弱、室内温暖反馈 | 精细热力学和复杂伤病 |
| 现实专注 | 可选的开始/暂停/结束计时；轻度提高安静活动倾向 | 强制任务打卡或连续签到 |
| 探索 | 2–3 个近处地点、少量材料和独特见闻、返回木屋 | 战斗与开放世界 |
| 长期成长 | 3–5 类生活痕迹、里程碑、时光手记、可靠存档 | 大量服饰、装备、经济系统 |
| 关系表达 | 用动作和环境为主，偶有可关闭的简短自然文字气泡 | 大量硬性对话或情绪分值条 |
| 猫狗 | 可见的睡眠、走动等少量动作 | 宠物资源养成和惩罚 |

## 可落地的自主行为优先级

```text
角色安全（危险天气时回屋）
  > 必要生活行为（如炉火明显减弱时添柴）
  > 个体作息（休息 / 喝茶 / 打理）
  > 偏好与环境动作（天气好时窗边驻足）
  > 现实专注轻微加权（读书 / 整理更可能发生）
```

状态和行为必须可解释：看到风雪变大后角色关闭窗边活动；听到收音机响，角色偶尔起身查看。**离线期间允许合理推进日常，但不能制造强迫性的缺席损失。**

## 首版可实现的技术状态样例

```json
{
  "world": {"weather": "blizzard", "day_phase": "night", "cabin_comfort": 73},
  "resident": {"activity": "reading", "energy": 61, "safety": "inside"},
  "focus": {"running": true, "minutes": 25},
  "inventory": {"firewood": 8, "radio_parts": 2},
  "journal": [{"type": "action", "text": "今晚整理了木架"}]
}
```

这里的舒适度和精力数值可只在模拟层存在，玩家看到的是生活场景，而非密密麻麻的参数表。

## 体验验证标准（首个 Web Demo）

- 10 秒内是否能感知“外冷内暖”？
- 25 分钟现实专注期间，角色无需点击是否仍自主生活？
- 专注期间不看游戏，回来是否看到**可解释**的生活变化？
- 一次外出采集并归家，是否产生“回到安全地方”的感受？
- 强制刷新/关闭页面后，物件与时光手记状态是否一致？
- 即使一周没打开，是否也不会被惩罚或催签到？

## P0 / P1 / P2

- **P0**：单场景、单角色、天气/炉火、专注计时、简单探索、回访、事件日志、持久化。
- **P1**：猫狗小动作、丰富声景、换季、可视化生活痕迹、更清晰的自主性反馈。
- **P2**：更多区域、角色深层关系、多阶段事件、可选互动对话和跨端同步。

要先验证**玩家是否愿意重新打开那个木屋**，再投入精细动画和复杂生存模拟。
