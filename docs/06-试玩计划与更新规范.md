## 标准试玩笔记

```markdown
# 游戏 / 版本 / 平台 / 日期
## 体验时间（分钟）
## 现场情境与玩家目标
## 首次感到安全/温暖/牵挂的具体瞬间
## 行动 → 系统反应 → 情绪
## 首次感到繁琐、催促或焦虑的瞬间
## 停留 30 分钟后/离开后/回来后有什么变化
## 角色行动是否有清晰因果
## 可以在 Web Demo 一周内验证的 1 个方案
## 不建议迁移的机制
## 证据：实录时间戳、官方链接、观察/推断标记
```

## 数据迭代

1. 核对 Steam app ID、官方页面、版本与英文名。
2. 确保只填一个主分类，并把末日题材与跨题材参考严格区分。
3. 描述**实际玩法事实**，将个人体验和迁移推测单独写。
4. 同时更新 JSON 和 CSV，运行 `python3 scripts/check_data.py`。
5. 复核 [统计快照](03-分类统计与机制矩阵.md) 的所有数字。
6. 新样本采用 PR，讨论评分争议与证据局限。

## 有价值的后续新增维度

- 游戏是否可**离线推进且不惩罚缺席**；现实专注时的中断代价。
- 角色自主性等级：固定动画、定时循环、根据环境决策、长期记忆。
- 回访动机：好奇心、情感牵挂、日记与痕迹、材料收益、强制签到。
- 生成成本：手工脚本、规则组合、动画资产、AI 在线推理。
- 国内玩家、移动端/桌面跨平台研究与真实试玩证据。
