# 八组重点案例深度拆解

采用“场景—行为—反馈—情绪—迁移—限制”结构。**场景/玩法基于链接的官方游戏介绍；情绪及迁移分析属于研究者推断**。

## 01. I Am Future：灾后世界也可以是温柔生活

- **场景**：被水淹没的城市屋顶，废弃家电、耕种区、可改造的栖身之所。
- **行为链**：拆旧物 → 寻材料 → 种植/烹饪 → 装修 → 与机器人相处。
- **反馈**：居住空间一步步从荒芜变温暖。
- **情绪**：末日被用作安全感的对照，而不是持续恐慌。
- **迁移**：小屋外的恶劣天气要真实；小屋内的平静也要真实。
- **不宜照搬**：大规模自动化、制造链和频繁繁琐采集。
- 来源：[Steam](https://store.steampowered.com/app/1658040/)

## 02. The Long Dark + Frostpunk：寒冷不是背景贴图

- **场景**：前者关注个体在雪原求生，后者围绕冰雪城市管理。
- **行为链**：看到天气恶化 → 做准备 → 进入庇护 → 维持热源。
- **反馈**：火光、温度、室外音效都能强化“安全的室内”。
- **情绪**：壁炉与热茶的温暖来自玩家知道外面很冷。
- **迁移**：极简温度状态 + 壁炉添柴事件 + 暴风雪声景。
- **不宜照搬**：复杂冻伤系统、饥饿惩罚、治理压力。
- 来源：[The Long Dark](https://store.steampowered.com/app/305620/) / [Frostpunk](https://store.steampowered.com/app/323190/)

## 03. 漂泊牧歌：有生命的庇护所

- **场景**：一群人生活在缓慢移动的巨兽背上。
- **行为链**：定居、建设、照顾巨兽、对抗污染与天气。
- **反馈**：巨兽状态和村庄状态互相影响。
- **情绪**：玩家既是在管理家，也是在照料同行者。
- **迁移**：屋内的小动物、炉火、角色不是纯装饰，它们以温和方式彼此影响。
- **不宜照搬**：把伙伴变成饥饿、好感度的惩罚条。
- 来源：[Steam](https://store.steampowered.com/app/1121640/)

## 04. FAR + Pacific Drive：载具成为无声的同伴

- **场景**：孤独旅途与废墟外部世界，移动工具承担家与防护的功能。
- **行为链**：出发 → 遭遇环境 → 保养修复 → 安全返回。
- **反馈**：玩家熟悉它的操作、声音、外观与损伤。
- **情绪**：物件因为被照顾，逐渐像伙伴。
- **迁移**：柴火架、旧收音机、茶壶、外套等日常物件可留下时间痕迹。
- **不宜照搬**：高频驾驶、关卡修理或时间限制。
- 来源：[FAR](https://store.steampowered.com/app/609320/) / [Pacific Drive](https://store.steampowered.com/app/1458140/)

## 05. Spiritfarer + Unpacking：用物件记录关系

- **场景**：照顾灵魂朋友、布置共同生活的地方；整理搬家物品。
- **行为链**：与角色相处或使用物件 → 场景发生轻微变化 → 后来回看。
- **反馈**：房间、家具和日常遗留物成为记忆载体。
- **情绪**：“过去一起经历过什么”无需大量旁白。
- **迁移**：木屋生活痕迹与时光手记双轨记录。
- **不宜照搬**：强制悲伤告别或堆叠无穷的装饰道具。
- 来源：[Spiritfarer](https://store.steampowered.com/app/972660/) / [Unpacking](https://store.steampowered.com/app/1135690/)

## 06. Rusty's Retirement + Spirit City + Virtual Cottage：安静地存在

- **场景**：用户现实里工作/学习，虚拟人物在角落做自己的事。
- **行为链**：现实开始专注 → 游戏自运行 → 偶尔看一眼 → 结束后回访。
- **反馈**：角色轻微活动、房间状态变化、声景连续。
- **情绪**：你不需要点击，它也没有停止生活。
- **迁移**：低打扰 UI、可选计时器、角色活动倾向轻度同步。
- **不宜照搬**：催促完成现实任务、把效率变成唯一成长货币。
- 来源：[Rusty's Retirement](https://store.steampowered.com/app/2666510/) / [Spirit City](https://store.steampowered.com/app/2113850/) / [Virtual Cottage](https://store.steampowered.com/app/1369320/)

## 07. Project Zomboid + RimWorld：角色自己的小故事

- **场景**：日常活动、天气、状态与意外事件互相作用。
- **行为链**：环境变化 → 角色决策 → 行动 → 世界变化 → 形成新的经历。
- **反馈**：发生的事件有前因后果，不只是随机一段文字。
- **情绪**：玩家可以逐渐了解角色，而不必全程操控它。
- **迁移**：少量行为状态、简单优先级与事件手记就能验证效果。
- **不宜照搬**：庞大的状态表、职业树和复杂 AI 规划。
- 来源：[Project Zomboid](https://store.steampowered.com/app/108600/) / [RimWorld](https://store.steampowered.com/app/294100/)

## 08. The Alters：伙伴有自己的愿望和边界

- **场景**：来自不同人生选择的分身一起经营移动基地。
- **行为链**：任务分工 → 独立诉求/反应 → 关系变化。
- **反馈**：同伴不是生产单位，也可能不赞同玩家的安排。
- **情绪**：独立意志增强真实的共处感。
- **迁移**：角色优先满足安全和自身日常，再选择性配合现实专注；可拒绝、延后。
- **不宜照搬**：高冲突人际管理和压力倒计时。
- 来源：[Steam](https://store.steampowered.com/app/1601570/)
